# Tarn-Versteck – Multiplayer (inspiriert von Meccha Chameleon)

Eigenständiges Hide-and-Seek-Tarnspiel mit echtem Multiplayer-Server.

## Lokal testen

npm install
npm start

Dann im Browser: http://localhost:3000

## Online hosten

Bei einem Node.js-Host (z. B. Render) als Web Service deployen.
Build Command: npm install
Start Command: npm start
